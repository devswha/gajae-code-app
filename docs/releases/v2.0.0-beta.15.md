# Gajae Code App v2.0.0-beta.15

Desktop build: 0.2.9. This is the first release whose macOS binary carries a
working production updater, so beta.14 installs can update in place.

## If you are on beta.14

The sidebar notice above Settings offers this version directly. Press
**Update** to download it, then **Restart to install** once it is verified.
The app closes briefly and reopens as beta.15.

## If you are on beta.13 or older

beta.13 cannot update itself. Quit it, install this DMG once, and launch the
copy in Applications. Your projects and settings are picked up as they were.

## What changed since beta.14

- Sidebar: the right rail is now the agent context surface — an Environment
  summary (directory, branch, changes), a WORK block with the session's task
  list, and an ACTION REQUIRED block for requests waiting on you.
- Sidebar: WORK now shows delegated agents live. When the model starts App
  delegation (`task`/`subagent`), the running agents appear under a compact
  Agents label and disappear the moment each child settles — completed,
  failed, or cancelled — without waiting for another tool call, and without
  resurrecting stale rows after a reload or restart.
- Browser: the bundled Chromium sidecar is replaced by a native WebView
  browser in the desktop app; the self-hosted server keeps the policy-driven
  backend choice.
- Chat: the composer keeps working on non-secure origins (plain HTTP on a
  LAN), and mobile keyboards no longer auto-open on picker popups.
- Server: GJC history reads cache their index per transcript revision, and
  linux-arm64 runtime bootstrap is supported.

## Validation and beta limitations

This release retains the source-test, signature, notarization, archive
integrity, version, updater-mode and data-safety gates.

- The beta.14 to beta.15 in-app update exercises the click-driven updater
  between two correctly built releases for the first time.
- The bundle's loader minimum is macOS 13.0; real macOS 13 execution is not
  yet verified.
- Keep important project work committed or backed up before testing. Updates
  do not promise automatic rollback of user-data changes.

macOS desktop targets Apple Silicon. Linux server archives remain
manual-update distributions. No Windows or Intel Mac installer is supplied.
