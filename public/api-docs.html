Local HTTP reference

Gajae Code App API

A small reference for checking a running app and asking its host system to reveal a file. These routes are designed for the local app, not as a remote automation service.

Before calling

Use the app's origin

Build each request from the origin serving this page. For example, when the app is at http://127.0.0.1:3001, the health URL is http://127.0.0.1:3001/health.

In desktop mode, API routes are admitted only after the desktop bootstrap has established the per-launch HTTP-only cookie. The health check is the exception. The browser session created by Gajae Code App supplies that cookie; callers should not try to manufacture credentials.

Local operation only. Opening a path asks the operating system to handle it. Send paths you trust, and keep the server on its intended local interface.

Availability

Health check

GET/health

Returns process identity and build information. It does not require desktop API authentication.

Response — 200

{
  "status": "ok",
  "product": "gajae-app",
  "protocolVersion": 1,
  "timestamp": "2026-09-01T12:00:00.000Z",
  "version": "0.0.0"
}
status
Always "ok" for a response from this handler.
product
The product identifier: "gajae-app".
protocolVersion
Current health response protocol number: 1.
timestamp
ISO 8601 timestamp generated when the response is sent.
version
Version of the running server build.

Host integration

Open a file with the operating system

POST/api/system/open-file

Verifies that a supplied absolute path exists, then delegates opening it to the host operating system. A successful request confirms that the opener command completed; the application selected by the system decides how to display the file.

JSON request body

{
  "path": "/absolute/path/to/report.txt"
}
path
Required string. It must be an absolute path to an existing filesystem entry.

Response — 200

{
  "success": true
}

Failure responses

Open-file errors

Errors from POST /api/system/open-file are JSON objects containing an error string.

400
{ "error": "An absolute path is required." }
404
{ "error": "File not found" }
500
{ "error": "Failed to open the file" }
